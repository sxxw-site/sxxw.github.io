GPS 경로 기록으로 걸어온 길을 나만의 시간 속에 남기세요.

발자취·TimeTrails는 프라이버시를 최우선으로 하는 GPS 경로 기록 앱입니다. 이동, 러닝, 자전거, 하이킹, 드라이브 경로를 자동으로 기록하고 지도 위에 발자취를 생생하게 그려내며 다녀온 도시를 밝힙니다. 계정 등록이 필요 없고 광고나 제3자 추적도 없으며, 경로 데이터는 기본적으로 사용자의 기기에만 저장됩니다.

TimeTrails

시간과 장소를 이어 나만의 이야기로

  • 01일상의 이동 경로와 거리를 자동으로 기록
  • 02현지 시간에 맞춰 매일의 경로와 활동 요약 생성
  • 03안개 탐험으로 다녀온 곳을 되돌아보기
  • 04걷기, 자전거, 운전 등 활동 유형 인식
  • 05선택적으로 사진을 가져와 경로에 추억 남기기
  • 06선택형 iCloud 개인 데이터베이스 백업 및 기기 변경 시 복원
  • 07발자취 인사이트 · 기록된 위치 수 · 도시 기록 분포
  • 08발자취 지구 · 픽셀 / 육지 윤곽 / 위성 이미지

기록도 당신의 것, 데이터도 당신의 것

계정도, 광고도, 제3자 추적도 없습니다. 경로는 기본적으로 기기에 저장되며, iCloud 백업은 완전히 선택 사항으로 당신의 Apple CloudKit 개인 데이터베이스에만 저장됩니다.
