Privacy

Effective date: 2026-11-15 · Shanghai Shuxia Xiaowu Network Technology Co., Ltd.

This policy applies to Harbor, provided by Shanghai Shuxia Xiaowu Network Technology Co., Ltd. Harbor plays video from services you configure. The current app has no developer account, advertising, analytics SDK or developer-operated telemetry service.

Data stored on your device

Server addresses, display names, usernames, queues, continuous-playback preferences and watch history are stored in the app’s data directory. Server passwords are stored in the system Keychain. Harbor currently provides no cloud sync between devices.

Links containing temporary tokens may be saved in queue, history or download records. Harbor itself has no feature that uploads your library or private videos to the developer. System backups, diagnostics and restoration are governed by your device settings.

Local discovery and server requests

With system permission, discovery uses Bonjour service information to find compatible devices, read names, addresses and ports, and check WebDAV availability. Discovery does not use saved passwords or sign in to your NAS.

Browsing, playing and downloading send requests directly to the server you choose. Authentication provides the login information that server requires. HTTP traffic is unencrypted and intended for trusted networks. HTTPS uses system certificate validation; Harbor does not bypass invalid certificates.

Your server operator may log IP addresses, request times and accessed files. That operator controls its own data practices. Configure only services you trust and are authorised to access.

Downloads and storage

Videos you download are stored in the app’s data directory on this device. Download records include the source address, title, server identifier, state, progress and file size. Source addresses may contain temporary tokens. The downloads directory is marked as excluded from cloud backup.

Completed downloads can play offline. Harbor currently does not provide background downloads, HLS / DASH offline storage, or download sync between devices.

Viewing and deleting data

You can edit or remove servers, manage the queue and clear watch history. Removing a server removes its saved connection, password, related online queue and history entries, and cancels its unfinished downloads.

Completed videos and their download-source records remain after a server is removed. Delete them separately in Local Videos. Deleting a download removes its local copy, download record and matching local queue and history entries; it does not delete the NAS original. Existing online history is managed separately.

The same token-bearing link may be stored in several lists. To remove it fully, check the queue, history and downloads. Keychain items may persist according to system rules; remove saved server connections before uninstalling if you want those passwords cleared.

TestFlight and feedback you send

When you use a beta through TestFlight, Apple handles testing data under its TestFlight terms, including automatically providing crash logs and beta usage data to Apple and the application provider. This platform behaviour is separate from Harbor integrating an analytics SDK.

Feedback you submit in TestFlight, including text or screenshots, may reach Apple and the developer. If you email support, we receive your message and attachments and use them to handle your request. Please omit server passwords, complete token-bearing links and private videos.

Updates and contact

This policy describes the current app. The date on this page is updated when the policy changes. For privacy, device-data management or feedback enquiries, contact neverfall@foxmail.com.
