Start recording a route

  1. 01

    Choose location permissions

    For continuous background recording, allow "Always" location and "Precise Location" when the system prompts you. You can change this anytime in system settings.

  2. 02

    Start recording

    Turn on recording the first time you open the app. You can always pause or resume within the app; you're in control.

  3. 03

    View your daily routes

    Look back on each day's route, mileage, stops, and activity summary in the calendar or on the map.

  4. 04

    Turn on backup when you need it

    If you want to restore when switching devices or sync across multiple ones, turn on iCloud data backup yourself in settings; it's off by default.

Transfer and import files

Uploading a file from your computer is the first step. Confirm its import on your iPhone to add the data to TimeTrails.

Check file requirements and other import options ↓
  1. 01

    Connect both devices to the same network

    Connect your iPhone and computer to the same Wi-Fi or local network. Keep TimeTrails open in the foreground on your iPhone during transfer and import.

  2. 02

    Start the transfer service on your iPhone

    Open More → Data Sync. On the Local Area Network Transfer screen, tap Start Service. The default port is 9527; use the complete address shown in the app.

  3. 03

    Upload the file from your computer

    Open that address in your computer’s browser and upload a compatible .db or .gpx file. The file appears in the import list on your iPhone. Uploading alone does not add it to your route database.

  4. 04

    Review and confirm the import on your iPhone

    Tap the file in the list and follow the recognized import option. If recognized as a current TimeTrails database, keep a backup of your current data and review the comparison before choosing Full Overwrite or Incremental (Add Missing Data).

DB · GPX · iOS

File requirements and the Files app

Read the separate migration steps for the older TraceApp ↗
  • DB

    Use a compatible database

    A .db file must use the TimeTrails format or a compatible older WCDB format. A matching filename extension does not make every SQLite database importable.

  • GPX

    Route points need timestamps

    GPX import reads timestamped trkpt and wpt points. Points without time information are skipped, so the imported point count can be smaller than the count in the original file.

  • iOS

    Open a file from the Files app

    In Files, share or open a compatible file with TimeTrails. The app copies it into its local import list. Tap the file there to recognize and confirm the import.
