隐私政策

生效日期: 2026-11-15 · Shanghai Shuxia Xiaowu Network Technology Co., Ltd.

本政策适用于 Harbor 应用，由 Shanghai Shuxia Xiaowu Network Technology Co., Ltd. 提供。Harbor 是用户自行配置视频服务的播放器，当前版本不设置开发者账号，不展示广告，也不集成分析 SDK 或开发者自建遥测服务。

本机保存的资料

服务器地址、显示名称、用户名、待播列表、连续播放设置和观看记录保存在设备的应用数据目录；服务器密码保存在系统钥匙串。当前版本不提供跨设备云同步。

带临时令牌的视频链接可能作为待播、观看记录或下载记录的一部分保存在本机。Harbor 本身没有将资料库或私人视频上传给开发者的功能。设备系统的备份、诊断与恢复按系统设置处理。

局域网发现和服务器连接

经系统允许后，局域网发现使用 Bonjour 服务信息查找兼容设备，读取其名称、地址和服务端口，并检查 WebDAV 服务。发现阶段不使用保存的密码，不会替你登录 NAS。

浏览、播放或下载时，Harbor 会直接请求你指定的服务器；启用认证时，会向该服务器提供所需登录信息。HTTP 不加密传输，适用于可信网络；HTTPS 使用系统证书验证，不提供无效证书绕过。

服务器运营者可能记录 IP 地址、请求时间和访问文件等信息，其处理方式取决于该服务器。请仅配置你信任并有权访问的服务。

下载和存储

主动下载的视频保存在本设备应用数据目录。下载记录包含来源地址、标题、服务器标识、状态、进度与文件大小，来源链接可能包含临时令牌。下载目录标记为不参与云备份。

完成的下载可离线播放。当前版本不提供后台下载、HLS / DASH 离线下载或设备间下载同步。

查看和删除数据

你可在应用中编辑或移除服务器、管理待播和清空观看记录。移除服务器会移除保存的连接和密码、关联的在线待播及观看记录，并取消相关未完成下载。

已完成视频及下载来源记录不会随服务器移除而删除，需要在“本地视频”中单独删除。删除本地下载会移除副本、该下载记录及对应本地待播和观看记录，不会删除 NAS 原文件；已有在线记录需另行管理。

不同列表可能各自保存同一带令牌链接。若希望完整移除，请分别检查待播、观看记录与下载。系统钥匙串可能按系统规则保留项目；建议在卸载应用前先移除保存的服务器连接。

TestFlight 测试和主动反馈

通过 TestFlight 使用测试版时，Apple 根据其 TestFlight 条款处理测试数据，包括自动向 Apple 和应用提供者提供崩溃日志与测试使用数据。这一平台行为不同于 Harbor 集成分析 SDK。

你在 TestFlight 提交的文字、截图等反馈可能由 Apple 和开发者接收。你主动发送支持邮件时，我们会接收该邮件及附件，并将其用于处理反馈。请勿在反馈中包含服务器密码、完整带令牌链接或私人视频。

政策更新与联系

本政策随当前功能提供，更新时会调整本页日期。有关隐私、设备数据管理或反馈的疑问，可联系 neverfall@foxmail.com。
