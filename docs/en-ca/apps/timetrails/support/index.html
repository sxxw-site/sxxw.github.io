FAQ

Get Started ↗
Does TimeTrails track my location all the time?

You control the recording and can pause it anytime. System location is used only for on-device track logging, and data is stored only on the device by default.

Location isn't being recorded?

In Settings → Privacy & Security → Location Services, set TimeTrails to "Always," and turn on "Precise Location" and Background App Refresh.

How do I restore an iCloud backup?

With the same Apple ID, iCloud enabled, and a working connection, you can restore or manually sync from "iCloud Data Backup" in Settings.

How do I completely erase my data?

You can erase on-device data in the app's settings; if iCloud backup is enabled, delete the cloud copy as well.
