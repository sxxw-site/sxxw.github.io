一、服务内容

本应用是一款纪念日、生日与倒数记录工具，主要功能包括：事件的创建、编辑、删除与回收站、公历/农历倒计时与正计时、年份与人生进度、本地提醒等。数据保存在设备本地，支持主动导出和导入 JSON 备份文件。本应用不提供账号登录、云同步或云备份服务；HarmonyOS 系统备份与设备迁移由系统及你的系统设置决定（详见隐私政策）。

二、用户责任

1. 你应在合法合规的前提下使用本应用，对自己创建的内容负责； 2. 卸载应用或更换设备可能导致本地数据丢失，请提前导出备份并妥善保管；导出的文件需由你自行保存、迁移和删除； 3. 你不得对本应用进行反向工程、破解或用于任何非法用途。

三、提醒功能说明

本应用的提醒依赖 HarmonyOS 系统的提醒代理（Reminder Agent）在本地投递。提醒能否准时到达，可能受系统电源管理、后台管控等因素影响。本应用会尽力保证提醒的可靠性，但不对提醒的绝对准时性作出保证，重要事项请勿仅依赖本应用提醒。
