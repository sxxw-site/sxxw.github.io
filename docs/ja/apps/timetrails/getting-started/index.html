最初の軌跡から始めよう

  1. 1

    位置情報の許可を選ぶ

    バックグラウンドで連続記録するには、システムの案内で「常に」の位置情報と「正確な位置情報」を許可してください。いつでもシステム設定で変更できます。

  2. 2

    記録を始める

    初回起動時に記録をオンにします。アプリ内でいつでも一時停止や再開ができ、記録の主導権はあなたの手にあります。

  3. 3

    毎日の軌跡を見る

    カレンダーや地図で、毎日のルート、走行距離、立ち寄り、アクティビティの概要を振り返れます。

  4. 4

    必要なときにバックアップをオンにする

    機種変更時の復元や複数デバイスでの同期が必要なら、設定で自分から iCloud データバックアップをオンにできます。初期設定ではオフです。
