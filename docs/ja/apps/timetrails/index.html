iPhone·iPad·Apple Watch · App Store

GPS で軌跡を記録し、歩んだ道を自分の時間の中に残そう。

足あと·TimeTrails は、プライバシーを最優先する GPS 軌跡記録アプリです。移動、ランニング、サイクリング、ハイキング、ドライブのルートを自動で記録し、地図の上に足あとを生き生きと描き出して、訪れた街を点灯させます。アカウント登録は不要、広告や第三者トラッキングもなく、軌跡データは初期設定ではあなたのデバイス内にのみ保存されます。

TimeTrails

時間と場所をつないで、あなただけの物語に

  • 01日々の移動軌跡と走行距離を自動で記録
  • 02現地時間に合わせて毎日の軌跡とアクティビティの概要を生成
  • 03霧の探索で訪れた場所を振り返る
  • 04徒歩、サイクリング、運転などのアクティビティを識別
  • 05任意で写真を取り込み、ルートに思い出を残す
  • 06任意の iCloud プライベートデータベースへのバックアップと機種変更時の復元
  • 07足跡インサイト · 記録ポイント数 · 都市記録分布
  • 08足跡地球 · ピクセル / 陸地輪郭 / 衛星画像

記録はあなたのもの、データもあなたのもの

アカウント不要、広告や第三者トラッキングもありません。軌跡は初期設定では本体に保存され、iCloud バックアップは完全に任意で、あなたの Apple CloudKit プライベートデータベースにのみ保存されます。
