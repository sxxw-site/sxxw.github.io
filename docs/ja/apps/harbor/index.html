Harbor · WebDAV / HTTP

自宅の NAS 用動画プレーヤー

iPhone、iPad、Mac から WebDAV に接続。動画を探して再生キューに追加したり、ダウンロードしてオフラインで視聴できます。

TestFlight ベータに参加↗使い方

0.0.1 の最新ビルドは、単体の音声・動画ファイル、一括ダウンロード、WebDAV フォルダのダウンロードに対応します。TestFlight の機能はインストールしたビルドによって異なります。公開リンクは iPhone・iPad 版で、対応する Apple シリコン搭載 Mac でも実行できます。

製品紹介使い方プライバシー利用規約オープンソース

使い方、プライバシーポリシー、利用規約は英語で提供しています。

フォルダからオフライン再生まで

  • →WebDAV のフォルダを閲覧し、現在のフォルダを検索。動画の形式とファイルサイズを確認できます。
  • →動画やサブフォルダを含むフォルダをキューに追加し、順序を変えて連続再生できます。
  • →システム再生と VLC 互換再生で MKV などの形式に対応。全画面での前後の動画への移動、端末内の履歴と続きからの再生が可能です。
  • →対応する単体の音声・動画ファイルをダウンロード。複数選択や WebDAV フォルダにも対応し、既存のタスクはスキップします。
  • →ダウンロードの進行状況を確認し、キャンセルや再試行が可能。完了した動画は Harbor の再起動後もオフラインで再生できます。

再生キューとローカル動画

接続情報と履歴は端末内に保存

Harbor 専用アカウントは不要です。広告や分析 SDK は含まれません。サーバーのパスワードはシステムのキーチェーンに保存し、再生とダウンロードは指定したサーバーに直接接続します。TestFlight のテストデータは別途説明しています。
