新增第一個紀念日

  1. 01

    新增紀念日

    進入紀念日頁面後選擇新增，填寫名稱、日期、類型與備註。需要時可選擇農曆日期。

  2. 02

    確認下一次日期

    儲存後，App 會根據日期和重複規則顯示下一次日期。農曆記錄會依對應規則換算。

  3. 03

    設定本機提醒

    在記錄中選擇提醒時間和提前天數。首次設定提醒時，請允許系統通知；關閉權限只會影響提醒，不影響記錄與瀏覽。

  4. 04

    管理本機資料

    刪除的記錄會先進入回收筒，可還原或徹底清除。你可以主動匯出或匯入 JSON 備份檔案，備份包含已設定的照片頭像。解除安裝會移除應用本地資料，請提前匯出並妥善保管；系統備份與裝置遷移由 HarmonyOS 和你的系統設定決定。
