✦出行轨迹 → TimeTrails

把数据迁移到足迹

你在「出行轨迹」里记录的轨迹，可以完整迁移到新版「足迹·TimeTrails」。几步即可完成，全程只在你的设备上处理，不会上传。

  1. 1

    获取「足迹」

    在本机安装并打开「足迹·TimeTrails」。

  2. 2

    打开「数据迁移」

    在足迹里进入 设置/更多 → 数据迁移。

  3. 3

    选择本 App 的 db 文件夹

    在足迹里点「导入」，然后在 文件 › 我的 iPhone › 出行轨迹 中选择整个「db」文件夹，等待导入完成。

须知

⇄导入的数据会与足迹里已有轨迹合并，不会覆盖，重复导入也不会产生重复点。
◆全程在本机完成，你的数据不会被上传。
