足迹-时光轨迹：記錄出行路線

足跡-時光軌跡 是一款隱私優先的 GPS 軌跡記錄 App。自動記錄出行、跑步、騎行、健行與駕車路線，在地圖上生動呈現足跡、點亮走過的城市。無需註冊帳號，不接入廣告或第三方追蹤，軌跡資料預設僅保存在你的裝置本機。

出行記錄與回顧

  • 01自動記錄日常移動軌跡與里程
  • 02依當地時間產生每日軌跡與活動摘要
  • 03用迷霧探索回顧去過的地方
  • 04辨識步行、騎行、駕車等活動類型
  • 05可選匯入照片，為路線保留回憶
  • 06可選 iCloud 私人資料庫備份與換機復原
  • 07足跡洞察 · 記錄點數 · 城市記錄分布
  • 08足跡星球 · 點陣 / 陸地輪廓 / 衛星影像

軌跡儲存與備份

無需帳號、沒有廣告或第三方追蹤。軌跡預設存於本機；iCloud 備份完全可選，僅進入你的 Apple CloudKit 私有資料庫。
