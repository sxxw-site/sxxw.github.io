Preguntas frecuentes

Comenzar ↗
¿Cómo ajusto el permiso de ubicación?

En «Ajustes → Privacidad y seguridad → Localización → TraceApp», elige «Al usar la app» o «Siempre»; también puedes desactivarlo cuando quieras.

¿Cómo borro los datos?

Puedes borrar registros individuales o todos dentro de la app; al desinstalarla se borran los datos locales. Si activaste iCloud, la copia sincronizada debe gestionarse aparte en iCloud.

¿Qué debo aportar al informar de un problema?

Se recomienda incluir los pasos para reproducirlo, el resultado esperado y el real, el modelo del dispositivo y la versión del sistema; puedes adjuntar capturas para facilitar el diagnóstico.
