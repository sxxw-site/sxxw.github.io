应用与媒体

Harbor 用于连接你自行配置的 WebDAV 或 HTTP / HTTPS 视频服务、播放和管理本地副本。除明确标注的原创演示视频外，Harbor 不提供影视目录、内容订阅或第三方视频授权。

请仅访问、播放、下载你拥有或获得授权的文件，并遵守服务器的使用规则和适用法律。媒体内容的权利归其各自权利人所有。

设备、连接与账号

你负责配置可访问的服务器、维护访问权限，并妥善保管设备和服务器凭据。请使用可信网络；HTTP 不加密传输。Harbor 无法控制服务器运营者、家庭网络或系统权限设置。

本机待播、观看记录和下载由你管理。删除本地副本不删除服务器文件，移除服务器也不会自动删除完成的下载。重要文件请在原服务器或其他适当位置保留备份。

测试版与功能范围

Harbor 当前处于 TestFlight 测试阶段。测试资格、可用设备、构建有效期及测试数据处理以 Apple TestFlight 显示和条款为准；测试版可能中断、变更或出现错误。

播放能力取决于所安装的构建、系统、设备、编码和文件。采用 VLC 兼容播放的构建支持 MKV 等常见容器；具体格式与编码范围请查看应用内“支持的格式”。兼容播放暂不提供 Teletext 字幕、画中画或 AirPlay；当前不包含 SMB 接入、NAS 转码或跨设备进度同步。下载需保持应用打开，不支持 HLS / DASH 离线保存。应用不保证所有 NAS、媒体文件或网络环境均兼容。

请按适用的 Apple 条款，在你拥有或控制的兼容设备上使用 Harbor。除适用法律、相关开源许可或授权另有允许外，不得擅自分发应用、冒用开发者身份或利用应用侵犯他人的权利。

Harbor 的应用软件、品牌及原创演示内容的相关权利由其权利人保留。本条款不限制法律规定不能排除的消费者权利。

第三方开源组件遵循其各自许可证。版本对应的组件源码、修改、许可及替换或重链接材料见“开源组件”页；本条款不限制这些许可证赋予的权利。

反馈、更新与联系

你可以停止使用应用或退出测试。功能、政策或条款更新会在相应页面说明。有关使用、版权或支持问题，请联系 neverfall@foxmail.com；请勿发送不必要的私人媒体或登录凭据。
