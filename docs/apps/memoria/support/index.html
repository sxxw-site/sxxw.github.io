技术支持

数据会同步到其他设备吗？

登录 iCloud 并开启同步后，数据会通过你的 iCloud 私有库在 iPhone、iPad 与 Apple Watch 间同步。

如何删除数据？

你可以在应用内删除记录；卸载应用会删除本地数据，iCloud 数据可在系统“设置 → iCloud”中管理。

提醒没有出现怎么办？

请确认记录已设置提醒，并在系统设置中允许本应用发送通知。关闭通知只会影响提醒，不影响记录本身。
