拾忆 新手引导

从首次创建到通知权限，快速开始使用 拾忆。

App Store · Memoria · 拾忆华为应用市场 · 拾忆

从第一条记录开始

  1. 1

    新建纪念日

    进入纪念日页面后选择新建，填写名称、日期、类型与备注。需要时可选择农历日期。

  2. 2

    确认下一次日期

    保存后，应用会根据日期和重复规则显示下一次日期。农历记录会按对应规则换算。

  3. 3

    设置本地提醒

    在记录中选择提醒时间和提前天数。首次设置提醒时，请允许系统通知；权限关闭只会影响提醒，不影响记录与浏览。

  4. 4

    管理本地数据

    删除的记录会先进入回收站，可恢复或彻底清除。卸载应用会删除本机应用数据；由于没有云端备份，换机或卸载后无法恢复。
