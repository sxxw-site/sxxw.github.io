从第一条记录开始

  1. 1

    创建第一条记录

    打开应用后选择新增，填写名称、日期和你想保留的备注。可按需要选择生日、纪念日、节日或自定义事件。

  2. 2

    选择日期规则

    生日和纪念日可使用公历或农历。农历记录会按规则计算下一次对应日期。

  3. 3

    设置提醒

    为重要日子开启本地通知，并选择当天或提前的提醒时间。通知权限关闭时，应用会提示你前往系统设置开启。

  4. 4

    按需开启同步

    如需在自己的 iPhone、iPad 与 Apple Watch 间同步，可在 iCloud 登录状态下开启同步。同步进入你的 CloudKit 私有数据库，开发者无法读取。
