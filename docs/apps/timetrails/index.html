GPS 轨迹记录，把走过的路留在自己的时间里。

足迹·TimeTrails 是一款隐私优先的 GPS 轨迹记录应用。自动记录出行、跑步、骑行、徒步与驾车路线，在地图上生动呈现足迹、点亮走过的城市。无需注册账号，不接入广告或第三方追踪，轨迹数据默认仅保存在你的设备本地。
