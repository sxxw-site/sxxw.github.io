从第一段轨迹开始

  1. 1

    选择定位权限

    如需后台连续记录，请在系统提示中允许“始终”定位和“精确位置”。你可以随时在系统设置中调整。

  2. 2

    开始记录

    首次进入后开启记录。你始终可以在应用内暂停或恢复，记录权在你手中。

  3. 3

    查看每日轨迹

    在日历或地图中回顾每天的路线、里程、停留和活动摘要。

  4. 4

    按需开启备份

    如需要换机恢复或多设备同步，可在设置中主动开启 iCloud 数据备份；默认关闭。
